8/26 盘后英伟达发布截至 7/26 的 FY27 Q2 财报：营收 962.21 亿美元超预期（市场预期约 923.8 亿），净利润 597 亿同比 +126%；数据中心占 92%，超大规模云收入 487 亿、AI 云/工业/企业收入 403 亿（+138%，增速已超过大云厂）。黄仁勋称"算力正在转化为收入"。盘后一度涨超 8%，并带动 SK 海力士、CoreWeave、Nebius 等产业链盘后齐涨。CFO 透露对前沿实验室投资额近 500 亿美元、未完订单超 2 万亿美元，并回应"循环融资"质疑称其仅占同期自由现金流一小部分。

Anthropic 与 HHMI Janelia 共建的 Model Hardware Standard 于 8/27 开放研究预览，目标给 AI Agent 一套操控物理设备的"USB-C 式"通用标准：用 read（如 get temperature）/ write（如 set temperature）原语统一驱动显微镜、液体处理器、离心机、移液机器人、机械臂、量子计算机激光等；硬件自带自然语言标签与安全限值，限值在设备端而非 prompt 端强制执行。首批伙伴含 Genentech、CMU、QuEra、华盛顿大学等；硬件支持方含 AWS Strands、Universal Robots、Hugging Face、Raspberry Pi、Tecan、QIAGEN 等。被比作继 2024 年 MCP（软件层）后的"物理层"标准。

为什么重要：Agent 首次有了跨厂商、跨设备的物理执行标准，把实验室/工厂的"胶水代码"工作下沉到设备层——若沿 MCP 路径成为事实标准，Anthropic 的杠杆将从"拥有接口"转为"背后最 capable 的模型"。

趋势判断 5 条

1 · 算力即收入，但 AI 疲劳已现

英伟达 +106% 财报把"算力即收入"叙事推到顶点，但 Alphabet 三个月蒸发 6920 亿、Yardeni 公开喊"AI 疲劳"，说明市场开始区分"有盈利的 AI 应用"与"烧钱的故事"。

2 · 开源分发权集中化

NVIDIA 拟收 Hugging Face 把"开放"的定价权交给单一算力霸主，社区中立性信仰受考；DeepSeek/智谱/阿里等国产开源底座成最大变量。

3 · Agent 从软件走向物理

Anthropic MHS（物理层 USB-C 标准）+ Hugging Face Microduck（399 美元可 RL 机器人）双线共振，具身智能从实验室/高价走向标准与平民化。

4 · 国产"三件套"闭环

智谱 GLM-5.3-Flash、阿里 Qwen3.8-Flash 用"高性能 + 国产算力 + 超低价"一次性闭环，性价比倒逼全球降价，海外旗舰商业模型定价承压。

5 · 安全成前沿模型刹车片

持久化 Agent + 自主攻防 + 百余家企业联署"集体响应"，安全成本被显式计入推理账单与系统架构，评估维度从"输出无害"扩到"行为可控"。

6 · GitHub 锁定 Agent 基建

热榜主线从"模型选型"转向"围绕模型搭可替换系统"——记忆 / 网关 / 调度 / 安全成为新开源主战场，模型本体退居次席。
