趋势判断（5 条）

① harness 成为新护城河

AVO 满分 vs 模型裸跑 30%，OpenAI/DeepSeek 开源 Harness，行业共识：Agent 竞争力从模型能力转移到运行时架构、工具编排与上下文管理。

② 价格战烧到旗舰层

GPT-5.6 Sol 首次降价，中国开源模型与国际竞品用更低单价抢企业 API 份额，前沿模型溢价开始松动。

③ IPO 竞速进入业绩兑现期

Anthropic(2 万亿预期) 逼 OpenAI(2027)。但部分估值支撑来自信贷结构（博通 SPV、英伟达担保），循环融资质疑仍在。

④ 算力全面金融化

许可费+股权+人才、表外债务、太空/电力/散热全链条资产化——"卖水人"逻辑外溢到每一个环节。

⑤ 具身智能从炫技到上岗

宇树 IPO +460%、935 亿融资、工厂真实部署；但六成设备仍在非生产岗，规模化商用仍是核心考验。

⑥ 安全成本计入推理账单

水印攻防、沙箱扫描、私有云安全系统同日升温；合规正把可追溯成本硬塞进产品体验。
