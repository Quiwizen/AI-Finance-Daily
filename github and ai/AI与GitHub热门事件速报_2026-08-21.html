Anthropic 智能体三件套正式 GA：Computer Use + Skills API + Files API，另加 Browser Use 工具

最高热度8/20 官方发布 生产级 AgentRPA 替代HIPAA 合规

Anthropic 宣布 Computer Use、Skills API、Files API 在 Claude Platform 全面可用（GA），同时新增 Browser Use 工具。四件组合起来构成一条完整工作闭环：从 Files API 读入原始材料 → 按 Skill 里封装的团队流程执行 → 用 Browser Use 在没有 API 的网页系统里提交 → 把成品文件写回 Files API。

关键升级在工程细节：GA 版 Computer Use 单轮可执行多个动作（不再一次模型调用只点一下），早期客户实测每任务往返调用减少 20–40%；Browser Use 读取页面无障碍树/结构而非像素坐标定位元素，布局变动不再导致误点；Skills 跑在 Anthropic 自带代码沙箱，开发者无需自建托管；Files API 新增自动过期、速率上限 ×5、每组织 1TB 存储。Computer Use 已纳入 BAA，可承接 HIPAA 监管工作负载。

为什么重要：过去 Agent 落不了地，缺的正是"团队流程接口 + 文件柜 + 浏览器精准操作"这三块地基。三件套转正意味着第一波被绕开护城河的是表单套娃型 SaaS 与传统 RPA——后者需要人工录脚本写规则，前者的价值就在重复填表。但要注意边界：Browser/Computer Use 仍是客户端工具集，Claude 只负责提议动作，真正的点击、凭据隔离、失败中断、审批卡点仍需开发者自建执行器；四件能力的数据边界也不统一（Files API 与 Skills 不在 ZDR 覆盖内）。

Stripe 约 75 亿美元收购 OpenRouter：Token 交易层被支付巨头收编

$7.5B 并购模型路由 中间件单元经济
